# Commonplace

A small, page-style collection of quotes — built with plain HTML, CSS, and vanilla JavaScript.

🔗 **Live site:** https://aklilut40-code.github.io/Quotes

## About

Commonplace shows one quote at a time, like a page from a kept notebook, instead of a scrolling grid. You can:

- Browse by category — Life, Wisdom, Success, Love, Courage, Humor, Creativity
- Step through quotes with previous / next, or shuffle to a random one
- Save favorites (kept in your browser, no login needed)
- Copy or share the quote on screen

## Tech

- HTML5 / CSS3
- Vanilla JavaScript
- Hosted for free with [GitHub Pages](https://pages.github.com/)
